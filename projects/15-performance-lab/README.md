# Project 15: Performance Profiling Lab

Choose one earlier project and profile it.

## Good Candidates

```text
Log Analyzer
CSV Expense Tracker
Mini ORM
Threaded Job Queue
```

## Learning Goals

- `Benchmark`
- `GC.stat`
- Object allocation
- `memory_profiler`
- `stackprof`
- `frozen_string_literal`
- Reducing unnecessary object creation

## Completion Criteria

- Establish a benchmark baseline.
- Identify a slow path or allocation hotspot.
- Compare performance before and after optimization.
- Explain why the optimization helped.
- Avoid optimizing purely by intuition.
