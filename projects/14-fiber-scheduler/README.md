# Project 14: Fiber-based Task Scheduler

Build a small cooperative task scheduler.

## Features

```text
schedule task
yield control
run tasks cooperatively
```

## Learning Goals

- `Fiber`
- Cooperative concurrency
- Non-blocking thinking
- Scheduler concepts
- The difference between threads and fibers

## Completion Criteria

- Run multiple fibers cooperatively.
- Explain how `Thread` and `Fiber` differ.
- Explain where fibers are useful and where they are not.
